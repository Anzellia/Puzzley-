# Anzellia Puzzle｜拼图｜パズル

一款移动端优先的传统拼图网页游戏。上传自己的图片后，即可在浏览器中完成拼图，并导出带有拼图轮廓与阴影效果的透明 PNG。

自分の画像をアップロードして遊べる、モバイルファーストのクラシックなジグソーパズルゲームです。完成した作品は、ピースの輪郭と影を残した透過 PNG として書き出せます。

**在线游玩 / 公開サイト：** [anzellia-puzzle.chenganniwang.chatgpt.site](https://anzellia-puzzle.chenganniwang.chatgpt.site)

---

## 简体中文

### 功能

- 上传图片，或从当前设备的本地图库中选择已保存的图片
- 固定 `3:2` 相框，内部画布分辨率为 `1200 × 800 px`
- 图片完整等比例缩放并居中显示，不裁切；空余区域保持透明
- 传统凹凸拼图轮廓，相邻碎片能够严密衔接
- 四个可直接选择的关卡：`2 × 2`、`3 × 4`、`10 × 15`、`14 × 21`（最多 294 块）
- 自动保存最近一盘未完成游戏，可从「上次拼到」恢复完整布局
- 左右两侧最多显示 6 个待用碎片，拖出后自动补充下一块
- 顶部可展开全部未归位碎片，支持长按取出
- 碎片可以自由拖动；靠近正确位置时自动吸附并锁定
- 支持双指缩放、移动相框，并可随时恢复默认视图
- 支持竖屏与横屏，横屏拥有更舒适的操作空间
- 支持简体中文、English、日本語，并记住语言选择
- 完成后可导出 `1200 × 800 px` 透明 PNG
- 支持重新开始、进入下一关和返回图库
- 删除本地图片前会进行二次确认

### 图片与隐私

图片只在玩家当前使用的浏览器中处理，并保存在浏览器的 IndexedDB 本地图库里。游戏不需要注册或登录，也不会把玩家上传的图片发送到应用服务器。

更换设备或浏览器、使用无痕模式，或者清除网站数据后，本地图库中的图片不会保留。

### 本地运行

要求 Node.js `22.13.0` 或更高版本。

```bash
npm run install:ci
npm run dev
```

构建生产版本：

```bash
npm run build
```

## 日本語

### 機能

- 画像をアップロード、または現在の端末に保存されたローカルギャラリーから選択
- 固定の `3:2` フレーム、内部キャンバス解像度は `1200 × 800 px`
- 画像をトリミングせず、縦横比を保ったまま中央に配置し、余白は透明に保持
- 隣り合うピースが正確につながる、クラシックな凹凸形状
- 直接選べる 4 ステージ：`2 × 2`、`3 × 4`、`10 × 15`、`14 × 21`（最大 294 ピース）
- 直近の未完成パズルを自動保存し、配置を含めて「続きから」再開
- 左右に最大 6 個のピースを表示し、取り出すと次のピースを自動補充
- 上部トレイですべての未配置ピースを閲覧し、長押しで取り出し
- ピースを自由にドラッグでき、正しい位置に近づくとスナップして固定
- 2 本指でフレームを拡大縮小・移動し、表示をいつでもリセット
- 縦画面と横画面の両方に対応し、横画面ではより快適に操作可能
- 简体中文、English、日本語の切り替えと設定保存に対応
- 完成作品を `1200 × 800 px` の透過 PNG として書き出し
- リスタート、次のステージ、ギャラリーへ戻る操作に対応
- ローカル画像を削除する前に確認ダイアログを表示

### 画像とプライバシー

画像はプレイヤーが使用しているブラウザ内だけで処理され、IndexedDB のローカルギャラリーに保存されます。登録やログインは不要で、アップロードした画像がアプリのサーバーへ送信されることはありません。

端末やブラウザを変更した場合、シークレットモードを使用した場合、またはサイトデータを削除した場合は、ローカルギャラリーの画像は保持されません。

### ローカルでの実行

Node.js `22.13.0` 以上が必要です。

```bash
npm run install:ci
npm run dev
```

本番用ビルド：

```bash
npm run build
```
